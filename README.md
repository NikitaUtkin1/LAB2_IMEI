# Лабораторная работа №2. Регулярные выражения и Unit-тесты.

Программа для поиска и проверки синтаксически корректных серийных номеров IMEI.

## Возможности:
- **Проверка одного IMEI:** поддерживает слитный формат, а также номера с пробелами и дефисами.
- **Поиск в файле:** читает .txt файлы и находит все 15-значные номера.
- **Поиск на веб-странице:** скачивает сайт по URL (библиотека requests) и извлекает IMEI из HTML-кода.

## Архитектура проекта:
- regex_logic.py — ядро программы (регулярные выражения и очистка).
- data_parser.py — модуль чтения файлов и парсинга веб-страниц.
- exceptions.py — собственные исключения для обработки ошибок сети и файлов.
- main.py — консольный интерфейс пользователя.
- test_*.py — unit-тесты (проверка позитивных и негативных сценариев).
